# 進捗・課題まとめスキル (Progress Report Skill)

## 目的
実装したバグ修正、検証結果、および現在直面している数値的・物理的課題を構造化し、わかりやすいレポートフ
ァイルとして出力する。

## 出力フォーマット
以下の構成に従って、Markdown形式（またはテキスト形式）でファイルに書き出すこと。
1. **プロジェクト概要 / 本日の目標**
2. **実施したこと・コードの変更点**（バグ修正の内容など）
3. **検証結果・数値的エビデンス**（解析解との比較、高速化の倍率など）
4. **現在直面している課題と原因分析**（ソルバーの挙動や未解決の問題）
5. **次に行うべきネクストステップ**

## ファイル保存の絶対ルール
1. 既存のレポートファイルを絶対に上書きして削除しないこと。
2. ファイル名は日付と時刻（タイムスタンプ）を含めた形式（例: `reports/progress_report_2026-08-27_1435.md`）にすること。
3. 同日に複数回作成する場合でも、時間を変えることでファイルが別々に保存され、履歴がすべて残るようにす>ること。
